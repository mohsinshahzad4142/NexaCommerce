# 🛍️ NexaCommerce - Modern E-Commerce Web Application

NexaCommerce is a feature-rich, high-performance e-commerce platform built with modern web technologies. It provides a seamless shopping experience with real-time cart management, flash sales, wishlist, product comparison, and recently viewed tracking.

## 🚀 Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **State Management:** React Context API
- **Deployment:** Vercel

## ✨ Core Features

- **Dynamic Homepage:** Hero banner, top categories, and featured products.
- **Flash Sales:** Live countdown timer with heavy discounts.
- **Advanced Product Management:** Add to cart, wishlist toggle, and product comparison table.
- **Recently Viewed History:** Tracks user browsing history dynamically.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
